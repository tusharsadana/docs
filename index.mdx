The Hercules External API gives your systems secure, programmatic access to the
platform. Upload contracts and transaction data, poll processing status, export
validation results, and subscribe to real-time webhooks — all through standard
REST endpoints with OAuth2 authentication.

<Note>
  Every upload runs through the **same processing pipelines** as the Hercules UI.
  The API is a different entry point into the same system, not a separate workflow.
</Note>

## Base URL

All endpoints are served under the `/v1` prefix:

```
https://api.hercules.ai/v1
```

<Note>
  Use the base URL provided by your Hercules contact — sandbox and production
  environments have distinct hostnames. Examples in these docs use
  `https://api.hercules.ai`.
</Note>

## Core concepts

- **OAuth2 client credentials** — each integration gets a `client_id` / `client_secret` pair and exchanges them for a 1-hour bearer token.
- **Targets** — a single upload endpoint routes files to the right pipeline via a `target` parameter (`contracts` or `preinvoice_data`).
- **Idempotency** — every upload carries a client-provided `external_id`, so retries never create duplicates.
- **RFC 7807 errors** — all errors are returned as standard Problem Details with a `correlation_id` for support.
